# Tubee

Les versions à télécharger de Tubee, l'application de bureau qui enregistre une vidéo, sa piste audio, sa transcription ou sa miniature.

Le site : https://tubee-phi.vercel.app

## Télécharger

La dernière version est sur la page [Releases](https://github.com/rmadore-1/tubee-releases/releases/latest).

| Système | Fichier | Configuration |
| --- | --- | --- |
| macOS | `Tubee-<version>.dmg` | macOS 13 ou plus récent, processeur Apple (M1 et suivants) |
| Windows | `Tubee-<version>-setup.exe` | Windows 64 bits |

L'application s'ouvre avec un compte abonné, à créer sur le site.

## Premier lancement

Les installateurs ne sont pas encore signés ; le système demande donc une confirmation.

- **macOS** : glisser Tubee dans Applications, l'ouvrir une première fois, puis aller dans Réglages Système > Confidentialité et sécurité et choisir « Ouvrir quand même ».
- **Windows** : dans la fenêtre « Windows a protégé votre ordinateur », choisir « Informations complémentaires », puis « Exécuter quand même ».

Chaque version indique l'empreinte SHA-256 de ses fichiers, pour vérifier un téléchargement.

**English.** Downloads for Tubee, a desktop app that saves a video, its audio track, its transcript or its thumbnail. Get the latest build from [Releases](https://github.com/rmadore-1/tubee-releases/releases/latest): the `.dmg` for macOS 13 or later on Apple silicon, the `-setup.exe` for 64-bit Windows. The installers are not signed yet: on macOS, open the app once, then choose "Open Anyway" in System Settings > Privacy & Security; on Windows, choose "More info", then "Run anyway". The app opens with a subscribed account, created on [the website](https://tubee-phi.vercel.app).
